# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

同一批次按壶次递交：审评员开壶时选择批次并声明壶序，服务端只接受「该批已成功壶数 + 1」，跳壶或重复壶序一律拒交。相邻两壶之间还要满足审评员设定的最短静置秒数，秒数不够同样拒交，并写明还差多少秒（静置秒数在独立的「静置设置」页修改，设为 0 表示不限制）。顶栏「壶次台账」进入按批次组织的壶次时间线专页。观察员可看时间线，但不能开壶、不能改秒数。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 对批次「春芽」交壶一成功；立刻交壶二因静置不足被挡，提示「还差 N 秒」。
5. 在「静置设置」页把秒数改成 0 后再交壶二，成功；顶栏「壶次台账」时间线上能看到壶一、壶二。
6. 重复壶序（再交壶一）、跳壶（直接交壶三）都被拒；observer 可看「壶次台账」，但开壶与改秒数接口均返回 403。
