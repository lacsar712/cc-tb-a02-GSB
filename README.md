# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

同一批次还要按壶次递交：开壶时选择批次并声明壶序，服务端只接受壶序等于该批已成功壶数加一，跳壶或重复壶序一律拒交；两壶之间须满足审评员在「静置设置」页设定的最短静置秒数，不足时拒交并写明还差多少秒。顶栏「壶次台账」进入独立时间线专页。观察员可看时间线，不可开壶、不可改秒数。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏「壶次台账」进入独立时间线专页，不在审评总表内。
5. 春芽先交壶一成功，立刻再交壶二因静置不足被挡，提示「还差 30 秒」。
6. 在「静置设置」页把秒数改成 0 后，再交壶二成功，时间线上能看到壶一、壶二。
7. 跳壶（如只交过壶一却声明壶三）或重复壶序都被拒交，提示当前只接受第几壶。
8. observer 可看壶次时间线，但开壶、改秒数均返回 403。
